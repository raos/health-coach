# HealthCoach

A locally-deployed personal health coaching app that acts as your coach, nutritionist, and health advisor. Powered by Claude AI, with integrations for Strava, Garmin Connect, and Hevy.

![Login](https://img.shields.io/badge/auth-Google%20OAuth-blue) ![AI](https://img.shields.io/badge/AI-Claude%20Sonnet%204.6-orange) ![Stack](https://img.shields.io/badge/stack-FastAPI%20%2B%20React-green)

---

## Features

- **AI Training Coach** — Weekly Tonal-specific strength plans (Upper/Lower split) generated by Claude, with a multi-turn chat interface for coaching questions
- **AI Nutrition Planner** — 7-day South Indian vegetarian meal plans with macros, recipes, and a weekly shopping list; cook-once dinner = next-day lunch
- **AI Health Advisor** — Weekly health insights using the Peter Attia / Andrew Huberman framework (VO2 max, sleep, HRV, body composition, recovery)
- **Dashboard** — Weight trend chart, goal progress (body fat % + VO2 max), and a merged activity feed from Strava + Hevy
- **Strava integration** — OAuth2 sync for cardio activities
- **Garmin Connect integration** — Sleep, HRV, body battery, steps, and VO2 max (supports MFA)
- **Hevy integration** — Strength workout history via API
- **Google OAuth login** — Secure sign-in; JWT sessions valid for 30 days

## Setup

### 1. Clone the repo

```bash
git clone https://github.com/raos/health-coach.git
cd health-coach
```

### 2. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in your credentials:

```ini
# Required for login
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-secret
JWT_SECRET_KEY=<run: python -c "import secrets; print(secrets.token_hex(32))">

# Required for AI features
ANTHROPIC_API_KEY=sk-ant-...

# Optional — enable each integration as needed
STRAVA_CLIENT_ID=
STRAVA_CLIENT_SECRET=
GARMIN_EMAIL=
GARMIN_PASSWORD=
HEVY_API_KEY=
```

### 3. Google OAuth setup (one-time)

1. Go to [Google Cloud Console](https://console.cloud.google.com) → **APIs & Services → Credentials**
2. Create an **OAuth 2.0 Client ID** (Application type: Web application)
3. Add authorized redirect URI: `http://localhost:8000/api/auth/google/callback`
4. Copy the Client ID and Secret into `.env`

### 4. Install backend dependencies

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 5. Install frontend dependencies

```bash
cd frontend
npm install
```

### 6. Start the app

```bash
# From the repo root — starts both backend and frontend
./start.sh
```

Or manually:

```bash
# Terminal 1 — backend
cd backend && source venv/bin/activate && uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 — frontend
cd frontend && npm run dev
```

Open **http://localhost:5173** and sign in with Google.

## API Reference

The backend exposes a full Swagger UI at **http://localhost:8000/docs** when running.

Key endpoint groups:

| Prefix | Description |
|--------|-------------|
| `POST /api/auth/google/...` | Google OAuth flow |
| `GET /api/dashboard/...` | Summary, weight trend, activity feed, goal progress |
| `POST /api/coach/training-plan` | Generate Claude training plan |
| `POST /api/coach/chat` | Multi-turn coaching chat |
| `POST /api/nutrition/meal-plan` | Generate Claude meal plan |
| `POST /api/health/insights` | Generate Claude health insights |
| `GET /api/strava/status` | Strava connection status |
| `POST /api/garmin/login` | Garmin login (MFA-aware) |
| `POST /api/weight/log` | Log a weight entry |

## Configuration Reference

All configuration is via `.env` at the repo root. See `.env.example` for the full list.

| Variable | Required | Description |
|----------|----------|-------------|
| `GOOGLE_CLIENT_ID` | Yes | Google OAuth client ID |
| `GOOGLE_CLIENT_SECRET` | Yes | Google OAuth client secret |
| `JWT_SECRET_KEY` | Yes | Secret for signing JWT tokens |
| `ALLOWED_EMAIL` | No | Restrict login to one Google account |
| `ANTHROPIC_API_KEY` | Yes | Enables all AI features |
| `STRAVA_CLIENT_ID` | No | Enables Strava activity sync |
| `STRAVA_CLIENT_SECRET` | No | Enables Strava activity sync |
| `GARMIN_EMAIL` | No | Enables Garmin sleep/HRV data |
| `GARMIN_PASSWORD` | No | Enables Garmin sleep/HRV data |
| `HEVY_API_KEY` | No | Enables Hevy strength workout data |

## Notes

- **Local only** — designed for personal use on localhost; not hardened for public deployment
- **Database** — SQLite at `backend/health.db`; never committed to version control
- **Garmin MFA** — if your Garmin account has MFA enabled, the Settings page will prompt for a one-time code each time the session expires
- **DEXA baseline** — the app is seeded with a baseline DEXA scan from 2026-03-13; update `database/engine.py` to change the seed data
