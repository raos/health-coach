# HealthCoach

A personal health coaching app that acts as your AI coach, nutritionist, and health advisor. Powered by Claude AI, with integrations for Strava, Garmin Connect, and Hevy — and a remote MCP server so you can log meals and query your health data directly from Claude on your phone.

![Auth](https://img.shields.io/badge/auth-Google%20OAuth-blue) ![AI](https://img.shields.io/badge/AI-Claude%20Sonnet%204.6-orange) ![Stack](https://img.shields.io/badge/stack-FastAPI%20%2B%20React-green)

---

## Features

- **AI Training Coach** — Weekly Tonal-specific strength plans (Upper/Lower split) generated by Claude, with a multi-turn chat interface for coaching questions and Hevy routine push
- **AI Nutrition Planner** — 7-day South Indian vegetarian meal plans with macros, recipes, and ingredient scaling; cook-once dinner = next-day lunch
- **Food Log** — Log meals by typing a description (Claude estimates macros) or via Claude on your phone; browse by date with ← → navigation
- **Nutritionist Chat** — Ask your AI nutritionist about healthy eating habits, food swaps, and eating-out suggestions; has full context of your food log, meal plan, and goals
- **Shopping List** — Auto-generated weekly shopping list with checkbox tracking and email delivery
- **AI Health Advisor** — Weekly health insights covering VO2 max, sleep, HRV, body composition, and recovery; generated from your Garmin data
- **Dashboard** — Weight trend chart, goal progress (body fat % + VO2 max), and a merged activity feed from Strava + Hevy
- **Remote MCP Server** — Connect Claude.app (iOS/Android) or Claude Desktop via a secure API key; 13 tools for logging meals, querying workouts, syncing data, generating plans, and more
- **Strava integration** — OAuth2 sync for cardio activities
- **Garmin Connect integration** — Sleep, HRV, body battery, steps, and VO2 max (supports MFA)
- **Hevy integration** — Strength workout history and exercise progress via REST API
- **Google OAuth login** — Secure sign-in; JWT sessions valid for 30 days

## Setup

### 1. Clone the repo

```bash
git clone https://github.com/raos/health-coach.git
cd health-coach
```

### 2. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` — at minimum fill in:

```ini
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-secret
JWT_SECRET_KEY=<python3 -c "import secrets; print(secrets.token_hex(32))">
ANTHROPIC_API_KEY=sk-ant-...
```

See `.env.example` for the full list of optional integrations.

### 3. Google OAuth setup (one-time)

1. [Google Cloud Console](https://console.cloud.google.com) → **APIs & Services → Credentials → Create OAuth 2.0 Client ID**
2. Application type: **Web application**
3. Authorized redirect URI: `http://localhost:8000/api/auth/google/callback`
4. Copy Client ID and Secret into `.env`

### 4. Install backend dependencies

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 5. Install frontend dependencies

```bash
cd frontend
npm install
```

### 6. Start the app

```bash
# From the repo root — starts both servers
./start.sh
```

Or manually:

```bash
# Terminal 1
cd backend && source venv/bin/activate && uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2
cd frontend && npm run dev
```

Open **http://localhost:5173** and sign in with Google.

## Database

SQLite at `backend/health.db` (never committed). Auto-created on first startup via `Base.metadata.create_all()`.

| Table | Model | Description |
|-------|-------|-------------|
| `weight_logs` | `WeightLog` | Daily weight entries |
| `dexa_scans` | `DexaScan` | DEXA body composition scans |
| `vo2max_logs` | `Vo2MaxLog` | VO2 max measurements |
| `strava_activities` | `StravaActivity` | Synced cardio activities |
| `hevy_workouts` | `HevyWorkout` | Synced strength workouts |
| `hevy_exercise_sets` | `HevyExerciseSet` | Individual sets per workout |
| `training_plans` | `TrainingPlan` | Claude-generated weekly training plans |
| `meal_plans` | `MealPlan` | Claude-generated weekly meal plans |
| `nutrition_logs` | `NutritionLog` | Individual logged meals (web or MCP) |
| `health_insights` | `HealthInsight` | Claude-generated health reports |
| `coach_conversations` | `CoachConversation` | Chat history (coach + nutritionist) |
| `oauth_tokens` | `OAuthToken` | Strava OAuth tokens |
| `garmin_daily_cache` | `GarminDailyCache` | Cached Garmin daily summaries |
| `user_profile` | `UserProfile` | Goals, preferences, calorie target |

Seeded on first run with DEXA baseline, VO2 max baseline, and user profile for Sandeep Rao.

## MCP / Claude Mobile Integration

The backend runs a remote MCP server that Claude.app (iOS/Android) and Claude Desktop can connect to. Once connected, you can say things like:

- *"I just had overnight oats with protein powder for breakfast"* → logs to food log with estimated macros
- *"What should I eat today?"* → pulls today's meal plan
- *"What's my workout today?"* → returns today's training plan exercises
- *"Sync my data"* → triggers Hevy + Strava sync
- *"Generate a meal plan for this week"* → creates a full 7-day plan

**13 tools available:** `log_meal`, `get_nutrition_log`, `get_meal_plan_for_day`, `get_todays_workout`, `get_recent_workouts`, `get_exercise_stats`, `get_health_metrics`, `get_health_summary`, `get_health_recommendations`, `log_weight`, `sync_data`, `generate_meal_plan`, `generate_training_plan`

### Setup (Claude Desktop)

Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "health-coach": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://<your-host>/mcp/sse?key=<MCP_API_KEY>"]
    }
  }
}
```

The full URL with your key is shown in the app under **Settings → Mobile Access (MCP)**.

## Configuration Reference

All config via `.env` at the repo root.

| Variable | Required | Description |
|----------|----------|-------------|
| `ANTHROPIC_API_KEY` | Yes | Enables all AI features |
| `GOOGLE_CLIENT_ID` | Yes | Google OAuth client ID |
| `GOOGLE_CLIENT_SECRET` | Yes | Google OAuth client secret |
| `JWT_SECRET_KEY` | Yes | Secret for signing JWT tokens |
| `ALLOWED_EMAIL` | No | Restrict login to one Google account |
| `STRAVA_CLIENT_ID/SECRET` | No | Enables Strava activity sync |
| `GARMIN_EMAIL/PASSWORD` | No | Enables Garmin sleep/HRV/steps data |
| `GARMIN_SESSION_DIR` | No | Token persistence dir (Railway: `/data/garmin_session`) |
| `HEVY_API_KEY` | No | Enables Hevy strength workout data |
| `MCP_API_KEY` | No | Enables Claude mobile/desktop MCP integration |
| `RESEND_API_KEY` | No | Enables PDF email delivery (meal/training plans) |

## Notes

- **Database** — SQLite at `backend/health.db`; never committed to version control
- **Garmin MFA** — cannot be disabled; Settings page prompts for OTP when session expires. On Railway, set `GARMIN_SESSION_DIR=/data/garmin_session` to avoid re-authenticating on every deploy
- **Email** — uses [Resend](https://resend.com) (not SMTP). Add `RESEND_API_KEY` to enable
- **DEXA / VO2 max seed data** — update `database/engine.py` to change the baseline measurements
