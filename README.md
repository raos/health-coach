# Health Coach

A multi-tenant AI health coaching app. Each user gets their own AI coach, nutritionist, and health advisor, powered by Claude AI, with per-user integrations for Strava, Garmin Connect, Hevy, and Telegram — and a personal MCP server so you can log meals and query your health data directly from Claude on your phone or desktop.

## Features

- **AI Training Coach** — Weekly strength plans generated by Claude, with a multi-turn chat interface and Hevy routine push. Equipment-aware (Tonal or gym). Upper/Lower split with quad- and hip-dominant lower days; cardio days include a core circuit.
- **AI Nutrition Planner** — 7-day meal plans with macros, recipes, and ingredient scaling; cook-once dinner = next-day lunch (Bobby Parish philosophy)
- **Food Log** — Log meals by typing a description (Claude estimates macros) or via Telegram/Claude on your phone; browse by date with ← → navigation
- **Nutritionist Chat** — AI nutritionist with full context of your food log, meal plan, and goals
- **Shopping List** — Auto-generated weekly shopping list with checkbox tracking and email delivery
- **AI Health Advisor** — Weekly health insights covering VO2 max, sleep, HRV, body composition, and recovery (Peter Attia + Huberman framework)
- **Dashboard** — Weight trend chart, goal progress (body fat % + VO2 max), and a merged activity feed from Strava + Hevy
- **Weekly Check-In** — 5-point self-assessment ratings (training adherence, energy, sleep quality, diet, stress) with history view
- **Telegram Bot** — Natural-language bot linked via your MCP API key; uses the same 14 tools as the MCP server so you can log meals, check workouts, and query data from any device
- **Remote MCP Server** — Per-user MCP API key; connect Claude.app (iOS/Android) or Claude Desktop; 14 tools for logging, querying, syncing, and generating plans
- **Strava integration** — OAuth2 sync for cardio activities (per user)
- **Garmin Connect integration** — Sleep, steps, body battery, resting HR, VO2 max via paste-data or push-data import
- **Hevy integration** — Per-user API key stored in profile; strength workout history and exercise progress via REST API
- **Weekly Summary Email** — Auto-sent every Sunday at 7:30 PM ET; covers weight, workouts, nutrition, and health metrics
- **Multi-tenant auth** — Google OAuth + magic link email; invite-code–gated sign-up; admin UI for user management
- **GDPR-friendly** — Per-user data export (ZIP), account deletion, conversation history wipe, consent logging

## Setup

### 1. Clone the repo

```bash
git clone https://github.com/raos/health-coach.git
cd health-coach
```

### 2. Create local PostgreSQL database

```bash
createdb health_coach_dev
```

### 3. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` — at minimum fill in:

```ini
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-secret
JWT_SECRET_KEY=<python3 -c "import secrets; print(secrets.token_hex(32))">
ANTHROPIC_API_KEY=sk-ant-...
ADMIN_EMAIL=your.email@gmail.com
DATABASE_URL=postgresql://localhost/health_coach_dev
```

See `.env.example` for the full list of optional integrations (Strava, Telegram, Resend, etc.).

### 4. Google OAuth setup (one-time)

1. [Google Cloud Console](https://console.cloud.google.com) → **APIs & Services → Credentials → Create OAuth 2.0 Client ID**
2. Application type: **Web application**
3. Authorized redirect URI: `http://localhost:8000/api/auth/google/callback`
4. Copy Client ID and Secret into `.env`

### 5. Install backend dependencies

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 6. Run database migrations

```bash
cd backend
alembic upgrade head
```

### 7. (Optional) Seed admin user

```bash
cd backend
python scripts/seed_admin_user.py
```

### 8. Install frontend dependencies

```bash
cd frontend
npm install
```

### 9. Start the app

```bash
# From the repo root — starts both servers
./start.sh
```

Or manually:

```bash
# Terminal 1
cd backend && source venv/bin/activate && uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2
cd frontend && npm run dev
```

Open **http://localhost:5173** and sign in with Google. The first login with `ADMIN_EMAIL` gets `is_admin=True` and skips the onboarding wizard. All other new users need an invite code.

## Authentication

### Sign-in flows

**Google OAuth** (primary):
1. User visits login page, optionally enters invite code, clicks "Continue with Google"
2. Frontend calls `GET /api/auth/google/url?invite=<code>` → redirects to Google (invite code encoded in `state`)
3. Google redirects to `GET /api/auth/google/callback` — validates invite (new users only), creates User + UserProfile, issues JWT
4. Backend redirects to `FRONTEND_URL/auth/callback?token=<jwt>`

**Magic link email** (fallback):
1. User enters email + invite code → `POST /api/auth/magic-link/send` → email sent via Resend
2. User clicks link → `GET /api/auth/magic-link/verify?token=<token>` → issues JWT, marks token used

### Invite codes
- New users (non-admin) must provide a valid invite code at sign-up
- Admin creates codes at `/admin` or via `POST /api/auth/invite-codes`
- Codes support `max_uses`, `expires_at`; first login with `ADMIN_EMAIL` (bootstrap) needs no code

### Session revocation
`POST /api/auth/logout` sets `User.last_logout_at`. `get_current_user()` rejects any token issued before that timestamp.

### Onboarding
New non-admin users are redirected to a 5-step onboarding wizard after first sign-in:
1. Personal details (name, DOB, height)
2. Health goals (BF%, VO2 max target, goal date)
3. Training preferences (device, days/week)
4. Nutrition preferences (dietary type, cuisine preferences)
5. Integrations (Hevy API key, Strava, etc.)

`ProtectedRoute` checks `onboarding_complete` from the JWT and redirects to `/onboarding` if false.

## MCP / Claude Mobile Integration

The backend runs a remote MCP server scoped per user. Each user has their own `mcp_api_key` stored in `UserProfile`. The key is shown under **Settings → Mobile Access (MCP)**.

Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "health-coach": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://<your-host>/mcp/sse?key=<YOUR_MCP_API_KEY>"]
    }
  }
}
```

**14 tools:** `log_meal`, `get_nutrition_log`, `get_meal_plan_for_day`, `get_todays_workout`, `get_recent_workouts`, `get_exercise_stats`, `get_health_metrics`, `get_health_summary`, `get_health_recommendations`, `log_weight`, `sync_data`, `generate_meal_plan`, `generate_training_plan`, `submit_weekly_checkin`

## Telegram Bot Integration

Connect the Telegram bot to your account using your MCP API key (same key used for Claude Desktop/mobile).

### Setup (one-time, admin)

1. Create a bot via [@BotFather](https://t.me/BotFather) and get your token
2. Add to `.env`:
   ```ini
   TELEGRAM_BOT_TOKEN=<token from BotFather>
   TELEGRAM_BOT_USERNAME=your_bot_name  # without @
   TELEGRAM_WEBHOOK_SECRET=<random string>
   ```
3. Register the webhook:
   ```bash
   cd backend && python scripts/setup_telegram_webhook.py
   ```

### Connecting as a user

In **Settings → Integrations → Telegram**, click the deep-link button to open the bot in Telegram — it auto-connects using your MCP API key. Or manually send `/connect <YOUR_MCP_API_KEY>` to the bot.

### Bot commands

| Command | Description |
|---------|-------------|
| `/start [mcp_key]` | Initialize; auto-connect if key provided via deep link |
| `/connect <mcp_key>` | Link your Telegram account to Health Coach |
| `/disconnect` | Unlink your account |
| `/status` | Check connection status |
| `/help` | Show command list |
| _(any text)_ | Claude processes via tool-use loop — log meals, check workouts, query data |

The bot reuses all 14 MCP tools, so everything you can do via Claude Desktop you can also do via Telegram.

## Notes

- **Garmin** — direct login has been removed. Data is imported via `POST /api/garmin/paste-data` (paste `usersummary` JSON from Garmin Connect DevTools) or `POST /api/garmin/push-data` (scripted). Settings UI has a paste panel; `scripts/garmin_import_json.py` handles batch import.
- **Email** — uses [Resend](https://resend.com) (not SMTP). Required for magic link auth and weekly summary emails.
- **Hevy API key** — per-user, stored in `UserProfile` (set during onboarding or Settings).
- **Weekly summary** — fires every Sunday 7:30 PM ET via APScheduler; sends only to users with `weekly_email_enabled=True` and a valid profile. No CC.
- **Admin UI** — `/admin` page is hidden from the sidebar for non-admin users; API routes enforce `require_admin()` dependency.
- **Sidebar goals** — BF% goal, VO2 max goal, and goal date shown at the bottom of the sidebar are pulled live from `UserProfile` (set during onboarding or Settings).
